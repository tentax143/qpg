About Exam Blueprints

Exam blueprints are specific configurations created from templates. They define the exact structure for a particular exam, including sections, marks distribution, and question types.

  • Select a template that matches your subject and class
  • You can customize the blueprint after creation
  • Blueprints are used by the question generator to create papers
  • Each blueprint can be used for multiple exam generations
